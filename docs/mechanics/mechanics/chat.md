# Чаты

<span class="oc-c-primary">**`"сообщение"`**</span> — отправляет ваше сообщение в  <span class="oc-c-warning">**Глобальный Чат**</span>. \
Его видят <span class="oc-c-success">**все**</span> игроки на сервере.

<figure><img src="/assets/изображение (56).png" alt=""><figcaption></figcaption></figure>

<span class="oc-c-primary">**`*"сообщение"`**</span> — отправляет ваше сообщение в **Локальный Чат**, а также выводит сообщение над головой\
Его видят все игроки в радиусе <span class="oc-c-warning">**`38`**</span> блоков от вас.<br>

<figure><img src="/assets/изображение (55).png" alt=""><figcaption><p>Сообщение из Локального Чата</p></figcaption></figure>

<span class="oc-c-primary">**`/msg | /m [ник_игрока] "сообщение"`**</span> — отправит ваше сообщение только указанному игроку.<br>
